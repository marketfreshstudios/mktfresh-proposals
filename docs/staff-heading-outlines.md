# Staff heading outlines

Each page has one H1. **Section H2** uses the Home section-heading style on the page background. **Card H2** remains a sans-serif title when the card or panel sits directly below the page H1. Cards within a section use H3; titled groups within those cards can use H4. A screen reader can navigate the same levels on narrow screens. Rows, tabs, field labels and status chips are not headings.
