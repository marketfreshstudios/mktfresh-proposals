The editor is a functioning text and quote editor rather than static prose. Editable names/descriptions, billing mapping disclosure, block reuse/reorder controls and real reference metadata account for spacing differences. Controls become visible on focus/hover around editable prose; white document paper remains readable in dark mode. No illustrative Brightline/Rowan content is shipped in application code.

Board 02 has genuine theme props and was rendered separately for light and dark. Board 05 is light-only; the gallery labels the light reference when displaying a dark application counterpart. It does not recolor a light reference and claim a dark source.

Automated checks cover no horizontal page overflow at all captured widths, keyboard sorting, search, From defaults, explicit AI price review, named send confirmation, note delivery, live client radio choices, preview safety and absence of client theme controls. Unit/database tests separately verify historic evidence preservation and choice resolution before billing. `check:neutral` confirms that financing rules and clause wording remain in seed data.

Phase 4 record/list/countersign layouts and Phase 5 complete Studio screens are outside this phase. No hosted migration or provider verification was performed.
