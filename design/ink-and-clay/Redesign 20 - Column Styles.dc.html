Column styles: what changed and why
Built from columns-editor.tsx, block-style-controls.tsx, columns.ts and block-style.ts. The data model doesn’t change: a column’s style is still a BlockStyle, and the columns block still has layout, gap and align.
  1. Out of the modal, into the Styles panel. Today “Block style” and “Column style” open a centered modal that covers the columns you’re styling. Now the Styles tab gets a This proposal / Selection switch, and styling a column opens Selection, so the page stays visible and every change previews live.
  2. Two clear levels. The old modal mixed layout with box style under one title. Now Columns (layout, gap, alignment, and a list of column styles) and Column N (background, padding, border, corners) are separate scopes, linked by a breadcrumb and a column switcher.
  3. Dropdowns become visible choices. Ten selects become segmented controls, layout thumbnails and color swatches, so each option takes one click and the current value is visible without opening anything. The contrast check sits right under the background.
  4. Clearer name for stacking space. “Margin above/below” only applies when columns stack on a phone, so it’s now grouped as “When columns stack on a phone: Above / Below”.
  5. Copy and paste style (new). Copy style stores the column’s whole BlockStyle. Paste style replaces the target’s style exactly, without merging, so the two columns end up identical. Available from the edit bar, the panel, the ⋯ menu, and ⌥⌘C / ⌥⌘V. A “Paste to all columns” shortcut handles the most common case.
  6. One style clipboard for blocks and columns. Blocks and columns share the same BlockStyle, so a style copied from a paragraph box can be pasted onto a column and the other way round. On contracts and signatures, background and border don’t apply; padding and spacing still paste, and a toast says what was skipped.
  7. Safe by default. Each paste is one undo step and shows a toast with Undo. The copied style lasts for the editing session and is shown in the panel with its source, so you always know what will paste. Paste is disabled until something is copied.
1aColumn selected. The edit bar names the column. The panel opens on Styles › Selection with the breadcrumb, the column switcher (a dot marks styled columns), Copy and Paste, then the box style. Paste stays disabled until a style is copied.
