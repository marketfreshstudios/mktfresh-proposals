What happens next
  1. The template’s content and default quote are copied into a draft.
  2. You edit the draft — content, quote lines, optional items.
  3. The readiness check mirrors the server’s send validation.
  4. Sending emails a private link and starts the reminder schedule.
  5. The client signs first. You counter-sign after.

An assistant connected to this workspace can create and edit drafts too. It can never send, sign, counter-sign or change billing.
